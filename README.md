# Birth Patterns Descriptive & Predictive Analytics
Static web dashboard (HTML/CSS/JS). No XAMPP or server needed.

## Run locally
Open `index.html` in a browser (or `npx serve`).

## Deploy: GitHub + Vercel
1. Create a GitHub repo and upload everything in this folder (index.html, style.css, app.js, data.js, vercel.json).
2. Go to vercel.com → Add New → Project → Import your GitHub repo.
3. Framework Preset: **Other**. Leave build command and output directory empty → Deploy.
4. Every `git push` redeploys automatically.

Note: 4,900 of 5,000 records are simulated (see Data Quality tab).
